# RiconoscimentoGesti
Riconoscimento in tempo reale delle lettere dell’alfabeto con MediaPipe Hands e un Random Forest scikit-learn. Il progetto include: Raccolta dati via webcam (estrazione feature normalizzate dai 21 landmarks x,y,z della mano) . Addestramento (pipeline StandardScaler + RandomForestClassifier). Predizione live con smoothing
